# Archived Plans

This folder stores implemented, superseded, parked, or otherwise non-active plans.

Rules:

- Do not treat archived plans as current instructions.
- Prefer `../../plans/README.md`, `../../plans/active.md`, `../../status/implementation-status.md`, and `../../architecture/current-architecture.md` for current context.
- When archiving a plan, leave a short note in the original plan or in `../../plans/README.md` only if that helps future agents find the canonical result.
