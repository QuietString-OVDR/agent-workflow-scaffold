# Share

This folder stores polished teammate-facing or externally shareable documents for branch `__BRANCH_NAME__`.
Documents created in this folder must be written in Korean.

Use document-type folders rather than destination folders:

- `guides/`
  - How-to guides, user/team instructions, walkthroughs, and operational notes.
- `specs/`
  - Review-ready specifications, contracts, and cross-team technical agreements.

Rules:

- Use this folder for Confluence-ready, review-ready, or cross-team documents.
- Do not put share docs in `plans/`, `architecture/`, or `spec/` unless they are also the canonical internal source.
- Branch docs should be English by default, but share docs in this folder must be written in Korean.
