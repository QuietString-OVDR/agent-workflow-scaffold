# Prepare Handoff

Read the active branch docs first:

1. `docs/branches/<branch-doc-dir>/README.md`
2. `docs/branches/<branch-doc-dir>/spec/technical-spec.md`
3. `docs/branches/<branch-doc-dir>/design/*.md`
4. `docs/branches/<branch-doc-dir>/plans/design-review.md`

Then write or update `docs/branches/<branch-doc-dir>/plans/next-agent-handoff.md`.

The handoff must include:

- Exact task.
- Required reading order.
- Allowed write scope.
- Do-not-modify scope.
- Constraints.
- Required verification.
- Codex review gate.
- Expected output.

If key requirements or scope are unclear, stop and ask for clarification instead of writing a vague handoff.
